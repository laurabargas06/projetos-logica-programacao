# 🚀 Projetos de Lógica de Programação

Este repositório reúne uma coleção de projetos desenvolvidos para praticar e consolidar conceitos fundamentais de programação, cobrindo desde alocação dinâmica de memória em C até automação com APIs em Python e Programação Orientada a Objetos em Java.

---

## 📌 Projetos em Destaque

### 🤖 Automação de Cotações com Alerta no Telegram
> **Linguagem:** Python

O principal destaque deste repositório! Uma aplicação em Python que permite selecionar uma cotação (de moedas/ativos) e envia automaticamente atualizações de preços diretamente para uma conversa ou grupo no Telegram via Bot API.

* **Destaques:** Uso de APIs REST, consumo de webhooks do Telegram e automação de scripts.

---

### 🏫 Sistema de Gestão Escolar
> **Linguagem:** Java

Aplicação voltada para a gestão de informações escolares, desenvolvida com foco nos pilares da **Programação Orientada a Objetos (POO)**.

* **Destaques:** Abstração, Encapsulamento, Herança e Polimorfismo aplicados à organização de alunos, turmas e notas.

---

### ✈️ Menu de Planejamento de Viagens
> **Linguagem:** C

Um sistema interativo via terminal para gerenciamento de passagens aéreas.

* **Destaques:** Manipulação avançada de ponteiros, estruturas de dados e **alocação dinâmica de memória (`malloc`)** para otimização de recursos.

---

## 🛠️ Tecnologias Utilizadas

* **Python** (Automação & Requests)
* **Java** (POO & Lógica de Negócio)
* **C** (Gerenciamento de Memória & Estrutura de Dados)
* **Git/GitHub** (Controle de Versão)
